Simple Interest Calculator
This project is a simple interest calculator.
Description
The Simple Interest Calculator calculates simple interest based on the principal amount, annual interest rate, and time period.
Formula
Simple Interest = (Principal × Rate × Time) / 100
Input
Principal: Initial amount of money
Rate: Annual interest rate
Time: Time period in years
Output
The calculated simple interest.
Example
Principal = 1000
Rate = 5
Time = 2
Simple Interest = (1000 × 5 × 2) / 100 = 100
